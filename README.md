# Кодексы РО

Статический справочник по документам «Россия Онлайн», предоставленным 15.09.2026.

## Открыть сайт

Откройте `index.html` в браузере. Поиск и калькулятор работают без установки программ и подключения к серверу. Все данные находятся в проекте; внешние шрифты и библиотеки не загружаются.

## Разместить на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Распакуйте `ro-codex-pages.zip` и загрузите **содержимое** архива в корень репозитория. Сам ZIP загружать не нужно. Файл `index.html` должен находиться на верхнем уровне, а не внутри дополнительной папки.
3. Откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. Выберите ветку с загруженными файлами (обычно `main`) и папку **/(root)**, затем **Save**.
6. После завершения публикации адрес сайта появится в разделе Pages.

Сборка и отдельный сервер для GitHub Pages не требуются. Пути относительные: сайт работает по адресу с именем репозитория.

[Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Что есть в справочнике

- 190 статей УК: 49 в Общей части, 141 в Особенной.
- Поиск по номеру, вложенным номерам и словам из полного текста; регистр и ё/е не мешают поиску.
- Фильтры по главе, ведомству, штрафу и отметке о судимости.
- Наказания, приоритет розыска, дополнительные взыскания, исходный текст.
- Калькулятор: наиболее строгая статья, полное сложение и упрощённый порядок с исключением для ст. 17.3.
- Выбор штрафа вместо лишения свободы по ст. 10.11 и ручной ввод назначенной суммы.
- Памятка из 9 шагов, сроки, разъяснение прав и ссылки на нормы.
- Полные 122 статьи ПК и 94 статьи Конституции, поиск по главам.
- Мобильная компоновка, управление клавиатурой, копирование расчёта.

## Как считаются наказания

- Сроки указаны в месяцах. «До» сохраняется как верхний предел; ст. 17.12.1 содержит точные 50 месяцев.
- По умолчанию применяется наиболее строгая статья (ст. 5.2 ч. 3 УК). Арифметическая сумма всегда доступна для сравнения.
- Полное сложение показывает сумму санкций; его применение требует решения суда или постановления прокуратуры. Частичное сложение и индивидуальное назначение наказания автоматически не определяются.
- Упрощённый порядок использует наиболее строгую статью с пределом 60 месяцев. Исключение для 17.3 включается вручную только при совершении оскорбления во время процессуальных действий.
- По ст. 10.11 размер и вид штрафа в тексте не указаны. Пустая сумма означает «не определена», а не ноль. Введённая сумма помечается как ручная.
- Возмещение ущерба, двукратное взыскание долга/штрафа и изъятие лицензии указаны отдельно и не прибавляются к штрафу.
- Отметка в протоколе при аресте определяется по ст. 5.8: приоритет 4–5. Общий статус судимости по ст. 1.9 и отметка в протоколе — разные понятия. Для неуточнённого вида штрафа автоматический вывод о судимости не делается.
- В текстах есть противоречия о штрафах: ст. 5.11 ч. 3 УК упоминает их в упрощённом порядке, а ст. 5.2 ч. 5 УК и гл. II ст. 2.9 ПК запрещают. Калькулятор помечает такой набор как недопустимый. Полномочия в ст. 5 УК также изложены неоднозначно.
- В ст. 11.12 пропущено слово «свободы» после «лишения». Исходная формулировка сохранена, 30 месяцев включаются в расчёт сроков.
- Пересчёта в реальное игровое время нет: соответствующий коэффициент в источниках не задан.

## Обновить документы

Для обновления данных нужен Node.js. Замените три исходных TXT, затем выполните из папки проекта:

```text
node scripts/build-data.cjs
node scripts/check.cjs
```

На GitHub загрузите обновлённые TXT и `data.js`. После изменения правил вручную пересмотрите памятку в `app.js`, расчёты в `logic.js` и дату импорта в `scripts/build-data.cjs`, `index.html`, `app.js`. Проверки текущего издания фиксируют количество статей и контрольные санкции; при новой редакции обновляйте ожидаемые значения после сверки источника.

## Локальная проверка

```text
node scripts/serve.cjs
```

Откройте `http://127.0.0.1:4173/fsb-ro-info/`. Остановить сервер: Ctrl+C.

## Файлы

- `index.html`, `styles.css`, `app.js` — интерфейс.
- `logic.js` — поиск и расчёты.
- `data.js` — данные из трёх исходных документов.
- `favicon.svg`, `.nojekyll` — значок и совместимость с Pages.
- `scripts/` — обновление данных, проверка и локальный просмотр.
- Три исходных TXT — доступны для скачивания из интерфейса.

Выбранные статьи сохраняются только на время открытой страницы. Переход между вкладками сайта сохраняет расчёт; перезагрузка страницы очищает его.
